# Bike Geometry Lab

Два инструмента для самостоятельного bike-fit: сравнение геометрий рам и модель посадки райдера на конкретной раме.

Паспортные цифры сравнивать глазами почти невозможно. «Reach 465 против 440» ничего не говорит, а две рамы, наложенные в одном масштабе, показывают разницу сразу. И уж тем более из таблицы не видно, во что эти числа поставят конкретного человека с его ростом, длиной ног и рук.

**Демо:** https://eugeneodnoval-collab.github.io/bike-geometry-lab/

## Страницы

**`index.html` — сравнение геометрий.** Две рамы наложены по задней оси, колёса на общей земле. Пересчёт под ход вилки и sag: рама доворачивается вокруг задней оси, углы и reach со стеком пересчитываются физически, а не по правилу большого пальца. Таблица «факт → паспорт → Δ», габарит для перевозки, экспорт в PDF, состояние кодируется в адрес страницы.

**`fit-lab.html` — райдер на геометрии.** Кокпит считается цепочкой от рулевого стакана до центра хвата, высота седла — из целевого угла колена, поза — обратной кинематикой от контактных точек. Две позы: сидя и атакующая стойка. Вид сбоку и сверху, RAD и RAAD, углы суставов с нормами, развесовка по седлу, педалям и ладоням. Плюс калибровка модели по боковому фото, лист «что выставить на велосипеде» и журнал итераций.

**`help.html` — справка.** Что означает каждое поле, откуда взять число или как измерить его самому, типичные значения и на что оно влияет. Начинать стоит отсюда.

## Как запустить

Скачать файлы и открыть любой двойным кликом. Ни сборки, ни зависимостей, ни интернета: ванильный JavaScript и инлайновый SVG, три самодостаточных HTML-файла, связанных относительными ссылками.

Свои велосипеды и мерки сохраняются в пресеты (`localStorage`), с экспортом и импортом в JSON — локальный файл и GitHub Pages это разные origin, общего хранилища у них нет.

## Разработка

```
node regress.mjs            прогнать регресс модели
node regress.mjs --update   зафиксировать новый эталон
```

108 кейсов, 5292 значения на реальных данных из `fixtures-evo.json`. Любая правка модели проходит через регресс — подробности в `CLAUDE.md`.

## Ограничения

Инструмент про хардтейлы и плоский или райзерный МТБ-руль. Задняя подвеска не моделируется, дропбар не выражается. Модель статическая: две фиксированные позы, динамики переноса веса нет. Антропометрические доли взрослые, для детей страница посадки неприменима — геометрия рамы при этом остаётся верной.

Полный список с объяснениями — в `FIT-MODEL.md` и в разделе «Чего модель не умеет» справки.
